## 6. 复测方法

使用以下 curl 命令可复现任意一段回测（以第 1 段为例）：

**1x 杠杆：**

```bash
curl -s http://localhost:8000/backtest/quick \
  -H 'Content-Type: application/json' \
  -d '{
    "symbol": "BTCUSDT", "interval": "5", "strategy": "long_short_flip",
    "initial_equity_usdt": 10000, "trade_amount_usdt": 100,
    "fee_bps": 10, "leverage": 1,
    "start_time_ms": 1718928000000, "end_time_ms": 1722988800000
  }' | python3 -m json.tool
```

**20x 杠杆：** 将 `"leverage": 1` 改为 `"leverage": 20`。

各段的 `start_time_ms` / `end_time_ms` 见 `/tmp/backtest_results.json`（1x）和 `/tmp/backtest_results_20x.json`（20x）。

## 7. 观察

### 7.1 策略整体

1. **盈利段占比稳定在 50%**：1x 和 20x 杠杆下盈利段都是 10/20，杠杆不改变信号方向的胜负比。
2. **杠杆放大收益也放大亏损**：20x 平均收益 ×15，但平均回撤 ×22，最差段亏损从 -0.25% 放大到 -7.42%。
3. **20x 中位收益转负**：-0.03%，说明多数段在 20x 下微亏，盈利段拉高了平均值。
4. **止损触发率不变**：601 vs 603 次，杠杆不影响止损触发频率（止损基于价格结构而非账户）。

### 7.2 按周期

5. **30m 在两种杠杆下都表现最好**：1x 时 80% 盈利段，20x 时 60% 盈利段但平均收益 +1.72%。结构稳定，适合操作。
6. **5m 交易频繁但收益差**：20x 下 8 段中仅 3 段盈利，平均亏损 -0.20%。手续费 + 频繁止损侵蚀严重。
7. **15m 在 20x 下最差**：#9 段亏损 -7.42%，是所有测试中最差的一段。
8. **4h 样本太少**：每段仅 4-7 笔交易，随机性大，但 4h 的盈亏幅度在 20x 下被显著放大。

### 7.3 结论

当前策略（多空翻转 + 笔级止损 + 固定保证金）在 1x 杠杆下基本持平，可作为 **基线对照**。后续策略优化（如改进信号过滤、动态止损、仓位管理）应使用相同的 20 个时间段做对照，观察 Sharpe 和收益的改善幅度。
