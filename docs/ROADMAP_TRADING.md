# 缠论买卖点识别与交易系统路线图

本文档描述产品与技术演进方向，**非业绩承诺**。回测指标（收益率、夏普等）需在统一数据集与风控假设下单独验证后再写入对外材料。

## 1）缠论买卖点识别（AI + 规则引擎）

- 基于 **近 2 年 K 线** 进行结构化训练与验证（标注 schema：分型 / 笔 / 线段 / 中枢 / 背驰 / 买卖点）。
- **规则引擎**：可解释、可审计的严格阶段闸门（结构不足不出点）。
- **AI 辅助**（可选）：在规则边界上做噪声消解、参数自适应或多级别一致性打分。
- **识别范围**：中枢结构，笔 / 线段演化，一买 / 二买 / 三买与一卖 / 二卖 / 三卖。
- **多周期联动**：**1H / 4H / 日线**（与当前 MVP 周期集合演进对齐时需另行设计与兼容）。

## 2）全自动化交易执行

- 信号生成 → 下单执行 → 持仓管理全流程自动化。
- 对接主流交易所 API（REST / WebSocket、密钥与速率限制策略）。
- 可扩展策略模块（多策略并行、路由与隔离）。

## 3）风控管理体系（Risk Control Engine）

- 仓位动态控制（Position Sizing）。
- 单笔风险限制。
- 最大回撤保护（Max Drawdown Protection）。
- 高频异常波动过滤。

## 4）移动止盈止损（Trailing System）

- 动态止盈（趋势跟随）。
- 自适应止损（基于结构 / 波动率）。
- 固定比例、ATR、缠论结构止损等模式可插拔。

## 5）回测（Backtesting）

- 回测周期：**近 1 年** 历史数据（可扩展到多市场）。
- 目标指标（需在同样成本模型下测定）：年化收益、夏普、最大回撤、胜率/盈亏比、换手与滑点敏感性。
- 多市场：加密货币 / 外汇等（数据源与交易时段规则需分别建模）。

## 与当前代码库的关系

- 当前仓库以 **现货行情 + 严格结构流水线 + 背驰证据** 的缠论分析为主；本路线图中的 **AI 训练、自动下单、组合风控、长周期回测** 为后续迭代范围。
