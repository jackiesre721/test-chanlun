# Chanlan：回测增强 · 固定仓位 · 信号追踪 — 产品与前端展示计划

面向当前 **单页结构**（顶栏 + 主图 + 单栏侧栏），侧栏卡片过多导致认知负载高。本计划在不强行做多路由的前提下，用 **分区（Tabs）+ 渐进披露 + 必要时抽屉/全屏层** 组织信息与后续功能。

---

## 1. 目标与原则

| 目标 | 说明 |
|------|------|
| 降低噪音 | 默认只看到「与当下看盘强相关」的内容 |
| 功能可发现 | 回测、风控试算、信号统计有固定入口，不靠无限滚动碰运气 |
| 与后端对齐 | 指标定义（胜率、期望值、回撤）与 `backtest_quick` / 未来 API 字段一致，避免两套口径 |
| 渐进增强 | 第一期只做 IA + 回测报告展示扩展；信号追踪依赖存储与后端时再接 |

**设计原则**：主图始终是视觉锚点；侧栏 **宽度不变**，通过 **Tab 切换** 换一批卡片，而不是把所有卡片垂直堆叠在同一屏。

---

## 2. 信息架构（IA）：侧栏四维分区

建议侧栏顶层使用 **分段控件（Tabs）**，对应四类心智模型：

```
┌─────────────────────────────────────────┐
│ [ 当下 ] [ 执行与风控 ] [ 研究与回测 ] [ 参考与设置 ] │
└─────────────────────────────────────────┘
```

### Tab A — 「当下」

**用途**：看盘决策语境，与当前 `symbol + interval` 强绑定。

| 模块 | 现有组件 | 说明 |
|------|----------|------|
| 简要结论 + GLM | `VerdictCard` | 保留；可折叠 GLM 原文 |
| 当下关注点 | `ActionFocusCard` | 保留 |
| 信号列表 | `SignalsCard` | 保留；后续可在此加「记入追踪」勾选项 |
| 结构状态 | `StructureStatusCard` | 保留 |

不再在本 Tab 塞：纸盘、回测、多周期、长篇说明。

### Tab B — 「执行与风控」

**用途**：头寸、纪律、模拟成交。

| 模块 | 现有组件 | 后续扩展 |
|------|----------|----------|
| 风控试算 | `RiskCalculator` | **固定仓位模式**：切换「风险比例 sizing | 固定数量 + 杠杆」，展示每笔名义价值 / 预估保证金 / 风险提示 |
| 纸盘 | `PaperTradingCard` | 可选默认折叠（Disclosure 默认收起） |
| 纪律 | `DisciplineCard` | 保留 |

### Tab C — 「研究与回测」

**用途**：假设检验、跨周期、历史表现。

| 模块 | 现有组件 | 增强方向 |
|------|----------|----------|
| 多周期 | `MultiTimeframeCard` | 保留 |
| 演示回测 | `BacktestCard` | **核心扩展区**（见 §3） |
| 信号表现追踪 | **新卡片** `SignalPerformanceCard`（占位） | 依赖「事件记录」API 与本地/DB 存储；第一期可只展示 UI 骨架 + 说明 |

### Tab D — 「参考与设置」

**用途**：低频、长篇、配置。

| 模块 | 现有组件 |
|------|----------|
| 进阶结构 | `AdvancedStructureCard` |
| 说明 | `ExplanationCard` |
| GLM 配置 | `GlmConfigCard` |

## 3. 回测增强：后端结果如何在前端展示

### 3.1 建议 API 形状（便于一次渲染）

在现有 `BacktestResult` 上扩展（字段名可按后端最终实现微调）：

```text
summary（顶层已有可保留）
├── total_return_pct, max_drawdown_pct, sharpe_ratio, trade_count
├── win_rate                    # 胜率
├── profit_factor               # 盈亏比相关（毛利/毛亏）
├── expectancy_per_trade        # 每笔期望值（同一币种口径）
├── max_consecutive_losses        # 最大连续亏损笔数
├── avg_win, avg_loss           # 可选

trades: TradeRow[]
├── entry_time, exit_time
├── entry_price, exit_price
├── side
├── pnl, pnl_pct
├── signal_kind_at_entry       # 与买卖点类型对齐，供分组统计
└── bars_held                  # 可选

stats_by_signal_kind: Record<string, { count, wins, losses, win_rate, avg_pnl }>
```

### 3.2 `BacktestCard` UI 分层（避免一坨文字）

1. **摘要条（常驻）**  
   一行 Chips：`收益 · 回撤 · Sharpe · 笔数 · 胜率`，点击某一 Chip 可在下方展开对应简短解释（tooltip 或小字）。

2. **次级指标（折叠面板）**  
   Disclosure：`期望值 · 盈亏比 · 最大连亏 · 按信号类型摘要表（迷你表）`。

3. **每笔明细（表格）**  
   - 默认折叠或默认只显示最近 **10** 笔，「展开全部」加载完整列表（虚拟滚动若笔数极大时再上）。
   - 列：`时间 | 方向 | 入场价 | 出场价 | 盈亏 | 持有 bars | 信号类型`。

4. **按信号类型统计（可选第二期）**  
   简单柱状图或条形对比（胜率 / 期望）：可用 ECharts 小图放在侧栏下半部分，或点击「查看图表」打开 **Modal / Drawer（宽度 480–640）**，避免侧栏过载。

### 3.3 空状态与加载

- 未运行时：保留现有简短说明 + 「运行演示回测」主按钮。
- 运行中：按钮 loading；可对摘要区 skeleton。
- 失败：沿用现有 error 样式。

## 4. 固定仓位模式（前端位置与交互）

**放置**：Tab「执行与风控」内的 `RiskCalculator` 顶部增加 **SegmentedControl**：`按风险比例 | 固定数量`。

- **固定数量**：输入数量 + 杠杆（已有杠杆 Select 可复用），展示「名义价值」「预估保证金」「单笔最大亏损（若配止损价）」。
- **风险金额**：若用户同时填止损与入场，可用现有几何推导展示「这笔你愿意亏多少钱」；与后端 `risk_controls` 已有逻辑对齐。

不要求第一期就做完整 DCA；可在卡片底部灰色小字写「DCA 为多笔分拆，后续版本」。

---

## 5. 信号表现追踪（产品占位 + 最终形态）

### 5.1 数据流（实现时分期）

1. **记录**：用户在 `SignalsCard` 或对某信号点击「追踪」→ 写入本地 IndexedDB 或后端表：`signal_id | symbol | interval | kind | idx | price | time | outcome_pending`。
2. **结算**：手动标记赢/亏，或在未来用「后续 N 根 K 极值」规则自动标记（需单独算法文档）。
3. **聚合**：按 `kind`、可选按品种/周期汇总胜率。

### 5.2 前端展示（Tab「研究与回测」）

- **卡片标题**：信号表现追踪  
- **上部**：筛选 Chips — `全部 | first | second | third | …`（与现有 signal kind 对齐）。  
- **中部**：小表格 — `类型 | 样本数 | 胜率 | 平均盈亏（若有）`。  
- **下部**：最近事件列表（时间、品种、类型、结果）。

第一期若无后端：**展示占位文案 + 「即将接入」**，避免空白卡片误导。

## 6. 页面级可选增强（非必须）

若后续侧栏仍挤：

| 方案 | 适用 |
|------|------|
| **回测全屏 Drawer** | 表格超过 ~15 行或要带图时，从右侧推出占屏宽 40–50% |
| **键盘快捷键** | `⌘/` 打开「面板索引」浮动菜单，跳到某一 Tab |
| **URL hash** | `#panel=research` 便于分享书签（仍算单页） |

第一期优先 **Tabs**，Drawer 留给「带图的详细回测报告」。

## 7. 实施顺序（建议）

| 阶段 | 内容 | 产出 |
|------|------|------|
| P0 | 侧栏 `SidebarTabs` + 四类分区迁入现有卡片 | 信息降噪，无新 API |
| P1 | `backtest_quick` 扩展字段 + `BacktestCard` 分层 UI（摘要 / 折叠 / 表格） | QuantConnect 式报告雏形 |
| P2 | `RiskCalculator` 固定仓位分支 + 文案 | 对齐「每笔同样数量」诉求 |
| P3 | 信号追踪存储 + `SignalPerformanceCard` | 统计哪类信号表现更好 |

---

## 9. 小结

- **认可**原先优先级：先做回测报告增强，再上固定仓位，再做信号追踪。  
- **前端解法**：单页不必拆路由即可减负 — **侧栏 Tabs 分区 + 回测卡片分层展示 + 重型内容 Drawer**。  
- 本文档可作为 PRD / 迭代 checklist；实现时以 `Sidebar` 重构 + `BacktestCard` 扩展为第一批合并单元。
