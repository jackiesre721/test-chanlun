交易纪律 · 生存与验证

1. 先让自己「不会死」

  • 单笔最大亏损：常见实盘自省区间约为净值 0.25%～1%/笔（非投资建议）。下面「风控试算」用风险比例 × 权益倒推出数量。
  • 连续回撤熔断：程序无法替你自动停机；用自检计数记录连续不利结果，达到阈值即提醒自己复盘而非「下一笔扳回来」。
  • 头寸：没有止损距离 → 谈不上头寸；请先填入场与止损再点「计算」。

2. 「信念」→ 假设 — 验证

  • 写出：入场 / 离场 / 不加不减条件，并指明对应引擎字段（如买卖点 kind、背驰 divergences）。
  • 用下方演示回测做多时段、多品种粗糙检验；再配合纸盘做流程演练（仍非实盘）。
  • 过拟合：务必对照左侧规则快照；改版规则后再谈曲线才有可比性。

3. 当前软件边界

  • 现货行情 + 结构可视化 + 纸盘记账；未建模真实手续费以外的滑点、深度、下单延迟。
  • /backtest/quick 为演示级简化撮合；实盘绩效通常弱于理想回测。
  • 实盘下单未接入；能重复执行的是流程与纪律，不是「看准这一波」。

4. 期望值视角

把盈利看成 正期望值 × 可重复次数；你能主动控制的主要是：输掉时亏多少、是否在系统失灵时停机。
